# Changelog

## 0.1.0

- Initial Lumi Nutcracker engineering preview.
- Root-supervised launch of explicitly selected workloads in owned cgroup-v2 units.
- Operator-triggered complete workload-tree termination using `cgroup.kill`.
- Automatic PID-limit tripwire containment.
- Dedicated workload/operator identity separation and control-socket authentication.
- Post-containment receipts, status, list, doctor and version commands.
- Clean installer, uninstaller, native qualification matrix and local AI smoke demonstration.
